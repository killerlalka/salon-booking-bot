# Бот записи клиентов для салона красоты

Telegram-бот, через который клиенты сами записываются на услуги — без звонков.
Подходит для салонов, барбершопов, мастеров маникюра, массажистов, автосервисов и любых услуг по записи.

## Возможности

**Для клиента**
- 📅 Запись за минуту: услуга → мастер → дата → свободное время → имя → телефон → подтверждение
- 👥 Несколько мастеров: у каждого своё расписание и свои услуги; можно выбрать «любого свободного»
- 🕐 Показывается только реально свободное время (с учётом длительности услуг и чужих записей)
- 📱 Отправка номера телефона одной кнопкой
- 🗂 «Мои записи» — просмотр и отмена своих записей
- ⏰ Автоматическое напоминание о визите за 2 часа
- 💅 Прайс-лист и 📍 контакты салона

**Для владельца**
- 🔔 Мгновенные уведомления о новых записях и отменах
- 🛠 Панель `/admin`: записи на сегодня, завтра и неделю, сумма выручки
- ❌ Отмена записи в один клик — клиент получает уведомление
- ⚙️ Услуги, цены, часы работы и выходные меняются в одном файле `config.py`

## Запуск на Windows

1. **Создайте бота в Telegram.** Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`,
   придумайте имя и username (должен заканчиваться на `bot`). BotFather пришлёт **токен** вида
   `1234567890:AAH...` — это пароль от бота, никому его не показывайте.
2. **Запустите `install.bat`** (двойной клик). Если Python не установлен, скрипт поставит его сам —
   после этого закройте окно и запустите `install.bat` ещё раз.
3. **Откройте файл `.env`** (Блокнотом) и вставьте токен после `BOT_TOKEN=`.
4. **Запустите `start.bat`.** Когда в окне появится «Бот @… запущен» — откройте бота в Telegram и нажмите «Старт».
5. **Сделайте себя администратором:** отправьте боту `/myid`, впишите число в `.env` после `ADMIN_IDS=`,
   закройте окно бота и снова запустите `start.bat`. Теперь вам доступна команда `/admin`
   и приходят уведомления о записях.

Бот работает, пока открыто окно `start.bat` и включён компьютер. Для работы 24/7 его размещают на сервере (VPS).

## Настройка под клиента

Всё в файле `config.py`:

| Что | Где |
|---|---|
| Название, адрес, телефон, часы работы | `SALON` |
| Услуги, цены, длительность | `SERVICES` |
| Мастера и какие услуги они делают | `MASTERS` |
| Начало и конец рабочего дня | `WORK_START`, `WORK_END` |
| Выходные дни | `DAYS_OFF` (0 — понедельник, 6 — воскресенье) |
| Шаг сетки времени | `SLOT_STEP_MIN` |
| На сколько дней вперёд открыта запись | `DAYS_AHEAD` |
| За сколько часов напоминать | `REMIND_BEFORE_HOURS` |

## Структура проекта

```
bot.py            — запуск бота
config.py         — все настройки
database.py       — хранение записей (SQLite, файл bookings.db)
schedule.py       — расчёт свободного времени
keyboards.py      — кнопки
notifications.py  — уведомления админам и напоминания клиентам
handlers/
  client.py       — сценарий клиента
  admin.py        — панель администратора
demo/index.html   — интерактивная демонстрация бота в браузере
```

Стек: Python 3.10+, aiogram 3, SQLite.
